# SSU PDF 다운로더

**숭실대학교 LMS의 주차별 강의자료를 한 번에 모아 받는 Chrome 확장 프로그램**

PDF를 하나씩 열어 저장할 필요 없이, 과목의 주차학습 자료를 스캔하고 일괄 다운로드할 수 있습니다.

## 주요 기능

- **전체 스캔:** 현재 과목의 주차별 PDF와 다운로드 가능한 첨부파일을 찾아줍니다.
- **전체 다운로드:** 찾은 자료를 한 번에 내려받고, 파일명에 주차 정보를 붙입니다.
- **자동 폴더 정리:** `학기 → 대시보드 → 과목` 순서로 자료를 분류합니다.
- **화면 전환 최소화:** 새 다운로드 탭이나 창을 열지 않고 저장을 시도합니다.
- **간단한 설정:** 과목별 학기를 지정하거나 Chrome의 기본 다운로드 위치를 변경할 수 있습니다.

## 사용 방법

1. 숭실대 LMS에 로그인하고 다운로드할 과목의 **주차학습**으로 이동합니다.
2. 확장 프로그램을 열어 **전체 스캔**을 누릅니다.
3. 학기와 과목이 맞는지 확인한 뒤 **전체 다운로드**를 누릅니다.
4. 지정된 다운로드 폴더에서 파일을 확인합니다.

## 저장 폴더 예시

```text
다운로드/
└── 2026년 2학기/
    └── 대시보드/
        ├── 고급Project/
        │   ├── 1주차_고급Project_01주차.pdf
        │   └── 2주차_고급Project_02주차.pdf
        └── SoC설계/
            └── 1주차_강의자료.pdf
```

다른 학기와 과목은 각각 별도 폴더로 정리됩니다. 저장 위치를 변경하려면 확장 프로그램의 **⚙ 설정 → 다운로드 폴더 위치 변경**을 이용하세요. 이 설정은 **Chrome 전체 다운로드**에 적용됩니다.

## 알아두세요

- 숭실대 Canvas·Commons 기반 학습자료를 대상으로 하며, LMS 환경에 따라 일부 자료는 다운로드되지 않을 수 있습니다.
- 로그인한 계정으로 열람·다운로드할 수 있는 자료만 이용해 주세요.
- 강의자료의 저작권과 학교 이용 규정을 지켜 주세요. 다운로드한 자료의 무단 공유·재배포는 삼가 주세요.
